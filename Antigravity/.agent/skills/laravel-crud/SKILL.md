# Laravel CRUD

## Steps
1. Create the migration and the model.
2. Create a resource controller with Form Request validation.
3. Add the routes in routes/web.php.
4. Create Blade views for index, create, edit, and show.

## Rules
- Do not edit the .env file.
- Use Laravel 11 conventions.
- Run the migration only after I approve.
