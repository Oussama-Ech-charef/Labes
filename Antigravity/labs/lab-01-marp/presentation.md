# Lab 01: Marp
Markdown Presentation Ecosystem

---

## What is Marp?
* Marp stands for Markdown Presentation Ecosystem.
* It provides a simple, intuitive way to create slide decks from Markdown documents.
* You can focus on your content rather than styling and formatting.

---

## Key Concepts
* **Marp Markdown**: Standard Markdown extended with Directives.
* **Frontmatter**: YAML block at the top enabling Marp (`marp: true`).
* **Paging**: Use `---` to separate slides.

---

## Directives
* **Global directives**: Affect the entire presentation (e.g., `theme`).
* **Local directives**: Affect the current and following slides (e.g., `backgroundColor`).
