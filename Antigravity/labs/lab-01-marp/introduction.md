# Introduction to Marp

## Purpose and Importance
Creating presentation slides can often be a tedious process involving dragging and dropping elements, aligning text, and dealing with formatting issues in traditional software like PowerPoint or Keynote. Marp (Markdown Presentation Ecosystem) solves this by allowing you to write your slides in plain text using Markdown.

By using Marp, you can focus purely on the content of your presentation. The styling and formatting are handled automatically through Markdown and Marp's built-in themes. This is especially useful for developers and writers who are already familiar with Markdown and want to version-control their presentations using Git.

## Learning Objectives
In this lab, you will learn:
* The core concept behind Marp.
* How to structure a Markdown file to act as a presentation.
* The basic directives used in Marp to control slide appearance.
* How to use the Marp CLI or VS Code extension to view and export slides.
