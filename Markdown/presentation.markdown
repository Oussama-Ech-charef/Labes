# Markdown

## What is Markdown?

* A simple markup language
* Used to format text
* Easy to learn and write
* Uses plain text and simple symbols

---

## Why Use Markdown?

* Simple
* Fast
* Easy to read
* Easy to edit
* Works on many platforms

---

## Basic Markdown

### Headings

```markdown
# Heading 1
## Heading 2
### Heading 3
```

### Text Formatting

```markdown
**Bold**
*Italic*
```

---

## Lists

### Unordered List

```markdown
- HTML
- CSS
- JavaScript
```

### Ordered List

```markdown
1. Learn
2. Practice
3. Build
```

---

## Links

```markdown
[GitHub](https://github.com)
```

---

## Images

```markdown
![My Image](image.jpg)
```

---

## Code

### Inline Code

```markdown
Use `console.log()`
```

### Code Block

````markdown
```javascript
````
