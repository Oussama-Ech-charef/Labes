# Marp

## What is Marp?

Marp is a tool that allows you to create **presentations using Markdown**.

Instead of designing slides manually, you write Markdown and Marp converts it into slides.

## Basic Configuration

```marp
---
marp: true
theme: default
paginate: true
---
```

## Create Slides

Use `---` to separate slides:

```markdown
# Slide 1

---

# Slide 2

---

# Slide 3
```

## Example

```markdown
---
marp: true
---

# My Presentation

## Markdown

- Simple
- Fast
- Easy

---

# Thank You
```

**Markdown + Marp = Presentation**
